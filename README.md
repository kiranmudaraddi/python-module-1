# Python Module 1 — GitHub Pages

Complete static student-facing website for Module 1: Python Programming Fundamentals (8 Hours).

## Upload to GitHub

1. Create a new GitHub repository, for example `python-module-1`.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the Pages URL.

No Python, Node.js, MkDocs, or build process is required.
