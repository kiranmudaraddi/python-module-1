01 · THE WAY OF THE PROGRAM

Start with the question: What does a computer actually do?

A program is a sequence of instructions written to solve a problem. Python lets us express those instructions in a readable way.

Think: If you give a computer a recipe, what must the recipe contain so that the computer can follow it?

The Python programming language

Python is a high-level, general-purpose programming language. A Python program is executed by the Python interpreter, which reads and executes Python instructions.

print("Hello, Python!")
Observe: The instruction asks Python to display text. The text inside quotes is a string.

What is a program?

A program is a collection of instructions that tells a computer how to perform a task or solve a problem.

What is debugging?

Debugging is the systematic process of finding, understanding and correcting errors in a program.

Syntax Error

The code breaks Python's grammar rules.

Runtime Error

The program starts but encounters a problem while running.

Semantic Error

The program runs, but produces the wrong result.

Experimental debugging

Use evidence rather than guessing.

Observe→Hypothesize→Change→Run→Check
# Semantic error
a = 10
b = 5
print(a - b)   # Is subtraction really what the problem asks?
Try it: Deliberately introduce one syntax error into a small program. Run it. Read the error message before fixing it.
02 · VARIABLES, EXPRESSIONS & STATEMENTS

Make the program remember things

Variables give names to values. Expressions combine values and operators to produce new values.

Values and data types

TypeExampleMeaning
int25Whole number
float3.14Decimal number
str"Python"Text
boolTrueLogical value
name = "Sam"
age = 20
cgpa = 8.4
print(name, age, cgpa)

Variable names and keywords

Names should be meaningful, cannot start with a digit, and cannot be Python keywords such as if, for, while, or def.

Operators and operands

a = 10
b = 3
print(a + b)
print(a * b)
print(a / b)
print(a % b)
print(a ** b)

Type converter functions

age = int("21")
price = float("99.5")
number = str(25)

Order of operations

Python evaluates expressions using operator precedence. Parentheses can make your intention explicit.

result = (10 + 2) * 3
print(result)
Predict → Run: What is the value of 10 + 2 * 3? Now compare it with (10 + 2) * 3.
03 · STRINGS & INPUT

Let the program talk to the user

Operations on strings

first = "Python"
second = "Programming"

print(first + " " + second)
print("Hi! " * 3)
print(len(first))
print(first[0])
print(first[0:3])

Input

name = input("Enter your name: ")
print("Hello", name)

input() returns text. Convert it when a numeric value is required.

age = int(input("Enter age: "))
print(age + 1)

Composition

Programs become useful when small operations are composed into a larger solution.

The modulus operator

print(17 % 5)   # remainder
Think: Where could a remainder be useful? Hint: checking whether a number is even.
n = int(input("Enter a number: "))
if n % 2 == 0:
    print("Even")
else:
    print("Odd")
04 · ITERATION

Teach the computer to repeat

Iteration means repeating a set of instructions. Python provides for and while loops.

Assignment and updating variables

count = 0
count = count + 1
count += 1
print(count)

The for loop

for i in range(1, 6):
    print(i)
Predict: How many times does the body execute? What values does i take?

The while statement

n = 1
while n <= 5:
    print(n)
    n += 1

Collatz 3n + 1 sequence

n = 6
while n != 1:
    print(n)
    if n % 2 == 0:
        n = n // 2
    else:
        n = 3 * n + 1
print(1)

Tables and two-dimensional tables

for i in range(1, 6):
    print(i, i*i)
for row in range(1, 4):
    for col in range(1, 5):
        print(row * col, end=" ")
    print()

break and continue

for n in range(1, 11):
    if n == 6:
        break
    print(n)
for n in range(1, 6):
    if n == 3:
        continue
    print(n)

Paired data

names = ["Asha", "Ravi", "Meena"]
marks = [82, 74, 91]

for name, mark in zip(names, marks):
    print(name, mark)

Nested loops for nested data

data = [[1, 2], [3, 4], [5, 6]]

for row in data:
    for value in row:
        print(value, end=" ")
    print()
Challenge: Write a program to print a 5 × 5 multiplication table using nested loops.
05 · FUNCTIONS

Build reusable pieces

A function groups instructions into a named, reusable unit. Arguments provide input and a return value sends a result back.

def add(a, b):
    return a + b

result = add(10, 20)
print(result)
Define

Use def to create the function.

Call

Pass arguments when you need the function.

Return

Send a result back to the caller.

Try: Create square(n) that returns the square of a number.
