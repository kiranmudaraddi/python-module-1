01 · THE WAY OF THE PROGRAM

Think like a programmer

Programming starts with a simple idea: give the computer precise instructions to solve a problem. A computer does not normally “understand” our intention. It follows the instructions we provide.

Connect to everyday life: Imagine giving a friend instructions to make tea. “Make tea” is not enough. You would need steps such as boil water, add tea, add milk, add sugar and serve. A program works in a similar way: a problem is converted into precise steps.

The Python programming language

Python is a high-level, general-purpose programming language known for readable syntax. It can be used for automation, web applications, data analysis, artificial intelligence, scientific computing and education.

When we write Python code, the Python interpreter reads the instructions and executes them.

print("Hello, Python!")
Observe: print() is a built-in function. The text inside quotation marks is a string value. Python executes the statement and displays the text.

What is a program?

A program is a sequence of instructions written to perform a task or solve a problem.

Input

Data supplied to a program.

age = 20
Processing

Operations performed on the data.

age + 1
Output

Information produced by the program.

print(age)

What is debugging?

Even experienced programmers write programs containing errors. Debugging is the systematic process of locating, understanding and correcting those errors.

Observe the problem→Find evidence→Form a hypothesis→Change→Run again→Verify

Three important types of errors

❌ Syntax Error

The program violates Python's grammar rules, so Python cannot understand the instruction.

print("Hello"

Fix: complete the parentheses.

💥 Runtime Error

The program starts running but encounters a problem during execution.

number = 10
print(number / 0)

Fix: prevent division by zero.

🤔 Semantic Error

The program runs but does not produce the intended result. The instructions are syntactically valid but logically wrong.

length = 10
width = 5
area = length + width

Fix: use the correct formula for area.

Experimental debugging

Experimental debugging means treating debugging like an investigation. Instead of changing many lines at once, change one small part, run the program, and use the result as evidence.

1. ObserveWhat is wrong?
2. IdentifyWhere might it happen?
3. HypothesizeWhat could be causing it?
4. ChangeMake one small change.
5. RunTest again.
6. ExplainDid the evidence support the idea?
Try: Write a program with one intentional error. Before fixing it, read the error message and describe what Python is telling you.
Takeaway: A good programmer does not merely fix errors. A good programmer learns from the evidence produced by the program.
02 · VARIABLES, EXPRESSIONS & STATEMENTS

Give names to information

Programs work with information. Python represents that information as values. Variables give useful names to values so that we can use them later.

Values and data types

TypeExampleUsed for
int25Whole numbers
float3.14Decimal numbers
str"Python"Text
boolTrueTrue/false decisions
name = "Asha"
age = 20
cgpa = 8.4
passed = True

print(name)
print(age)
print(cgpa)
print(passed)

Variables

A variable is a name that refers to a value. The statement below assigns the value 25 to the variable age.

age = 25

Think of age as a label attached to a value. The assignment operator = means “store/refer to this value with this name”; it is not the same as mathematical equality.

Variable names and keywords

Use meaningful names. Names may contain letters, digits and underscores, but they cannot begin with a digit. Python keywords have special meanings and cannot be used as ordinary variable names.

student_name = "Ravi"   # good
total_marks = 85        # good

# 2marks = 20           # invalid
# class = "CSE"         # invalid: keyword

Statements and expressions

A statement is an instruction that Python can execute. An expression is a combination of values, variables and operators that produces a value.

x = 10 + 5       # statement containing an expression
result = x * 2    # statement
print(result)     # statement

Operators and operands

a = 10
b = 3

print(a + b)   # addition
print(a - b)   # subtraction
print(a * b)   # multiplication
print(a / b)   # division
print(a // b)  # floor division
print(a % b)   # remainder
print(a ** b)  # power

In a + b, a and b are operands and + is the operator.

Type converter functions

User input normally arrives as text. Conversion functions allow us to convert values to another type.

age = int("20")
price = float("99.50")
code = str(2026)

print(age + 1)
print(price + 10)
print(code)

Order of operations

When an expression contains several operators, Python follows precedence rules. Parentheses have the highest priority among these common arithmetic operations.

print(10 + 2 * 3)       # multiplication first
print((10 + 2) * 3)     # parentheses first
Predict: Before running these two statements, write their results. Then run them and explain the difference.
Takeaway: Variables store useful information, expressions calculate values, and statements tell Python what to do.
03 · STRINGS, INPUT & COMPOSITION

Make programs communicate

A string is a sequence of characters. Strings are used for names, messages, labels, sentences and many other kinds of text.

Creating strings

name = "Kiran"
course = 'Python Programming'

Operations on strings

first = "Python"
second = "Programming"

print(first + " " + second)  # concatenation
print("Hi! " * 3)            # repetition
print(len(first))            # length
print(first[0])              # indexing
print(first[0:3])            # slicing

Concatenation joins strings. Indexing accesses a character. Slicing extracts a portion of a string.

Input

The input() function pauses the program and waits for the user to enter data. The returned value is a string.

name = input("Enter your name: ")
print("Hello", name)

Input with numbers

age = int(input("Enter your age: "))
next_year = age + 1
print("Next year:", next_year)
Observe: Without int(), the value from input() would be text. Converting it allows arithmetic.

Composition

Composition means combining simple operations to create a larger solution. For example, input + conversion + calculation + output can form a complete program.

length = float(input("Length: "))
width = float(input("Width: "))

area = length * width

print("Area =", area)

The modulus operator

The modulus operator % gives the remainder after division.

print(17 % 5)   # 2
print(20 % 4)   # 0

It is useful for checking even/odd numbers, repeating patterns, cycles and divisibility.

n = int(input("Enter a number: "))

if n % 2 == 0:
    print("Even")
else:
    print("Odd")
Try: Build a small program that asks for two numbers and displays their sum, difference, product and remainder.
04 · ITERATION

Teach the computer to repeat

Many programming tasks contain repetition: printing numbers, processing marks, generating tables or checking each item in a collection. Iteration allows a program to repeat instructions efficiently.

Assignment and updating variables

count = 0
count = count + 1
count += 1
print(count)

The value of a variable can change during program execution. This is called updating the variable.

The for loop

A for loop is useful when we want to repeat an action for each value in a sequence or range.

for i in range(1, 6):
    print(i)

range(1, 6) generates 1, 2, 3, 4 and 5. The stopping value 6 is not included.

Predict: How many times will the body execute? What is the final value printed?

The while statement

A while loop continues as long as its condition is true. The programmer must ensure that the condition eventually becomes false.

n = 1

while n <= 5:
    print(n)
    n += 1
Watch out: If you forget to update n, the condition may remain true forever and create an infinite loop.

The Collatz 3n + 1 sequence

For a positive integer n: if it is even, divide it by 2; if it is odd, multiply it by 3 and add 1. Continue until reaching 1.

n = 6

while n != 1:
    print(n)

    if n % 2 == 0:
        n = n // 2
    else:
        n = 3 * n + 1

print(1)

This example combines variables, modulus, selection, integer division and iteration.

Tables

number = 5

for i in range(1, 11):
    print(number, "x", i, "=", number * i)

Two-dimensional tables

When data has rows and columns, nested loops are often useful.

for row in range(1, 4):
    for col in range(1, 5):
        print(row * col, end=" ")
    print()

The outer loop controls the rows. The inner loop completes all columns for the current row.

break statement

break immediately terminates the nearest loop.

for n in range(1, 11):
    if n == 6:
        break
    print(n)

continue statement

continue skips the remaining statements in the current iteration and moves to the next iteration.

for n in range(1, 6):
    if n == 3:
        continue
    print(n)

Paired data

Sometimes two sequences contain related information. zip() can pair corresponding values.

names = ["Asha", "Ravi", "Meena"]
marks = [82, 74, 91]

for name, mark in zip(names, marks):
    print(name, mark)

Nested loops for nested data

data = [[1, 2], [3, 4], [5, 6]]

for row in data:
    for value in row:
        print(value, end=" ")
    print()
Challenge: Create a 5 × 5 multiplication table using nested loops. Then modify it to print only even products.
Takeaway: Use for when iterating through a known sequence/range, and while when repetition depends on a condition.
05 · FUNCTIONS

Break a problem into reusable pieces

As programs become larger, putting everything into one long sequence makes them difficult to understand and test. A function groups related instructions into a named unit that can be called whenever needed.

Function with arguments and return value

def add(a, b):
    result = a + b
    return result

answer = add(10, 20)
print(answer)
Function definition

def add(a, b): creates the function.

Arguments

10 and 20 are values passed to the function.

Return value

return sends the calculated result back to the caller.

Why use functions?

  • Reduce repetition.
  • Make programs easier to read.
  • Make testing easier.
  • Divide a large problem into smaller problems.
  • Reuse the same logic with different inputs.

Example: square of a number

def square(n):
    return n * n

print(square(5))
print(square(12))

Example: checking even number

def is_even(n):
    return n % 2 == 0

number = int(input("Enter number: "))

if is_even(number):
    print("Even")
else:
    print("Odd")
Try: Write maximum(a, b) that returns the larger of two numbers. Then test it with at least three pairs of values.
Takeaway: Functions help us turn a large problem into small, understandable and reusable pieces.
